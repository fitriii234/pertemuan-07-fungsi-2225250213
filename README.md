## Tujuan
Mempelajari fungsi, parameter, return value, dan scope untuk membuat program Python yang modular.

## Struktur Fungsi
1. `salam()` menampilkan salam kepada pengguna.
2. `luas_persegi_panjang()` menghitung luas persegi panjang.
3. `luas_segitiga()` menghitung luas segitiga.
4. `jumlah_n()` menghitung jumlah bilangan 1 sampai n.
5. `faktorial()` menghitung faktorial bilangan.
6. `statistik()` menghitung nilai minimum, maksimum, dan rata-rata.
7. `demo()` mempelajari local scope dan global scope.
8. `tampilkan_menu()` menampilkan pilihan operasi.

## Cara Menjalankan
Jalankan melalui terminal VS Code:

```powershell
python praktik/utilitas_matematika.py
```

## Hasil Pengujian

| Operasi | Input | Hasil |
|---|---|---|
| Luas persegi panjang | p=8, l=5 | 40 |
| Luas segitiga | a=10, t=6 | 30.0 |
| Jumlah 1 sampai n | n=10 | 55 |
| Faktorial | n=5 | 120 |
| Faktorial | n=0 | 1 |

## Refleksi
Penggunaan fungsi membuat program lebih rapi dan mudah dipahami. Parameter digunakan untuk menerima input, sedangkan `return` digunakan untuk mengembalikan hasil perhitungan agar dapat digunakan kembali.
